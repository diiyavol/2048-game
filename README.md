# 🎮 2048 Game

> A classic and engaging 2048 puzzle game, built using modern web technologies. Combine tiles, add up the numbers, and try to reach the coveted 2048 tile! 🧠✨

* **JavaScript** ⚡
## 🕹️ Controls

The game is controlled using the **arrow keys** on your computer keyboard:
* **↑ (Up)** — shift all tiles upward
* **↓ (Down)** — shift all tiles downward
* **← (Left)** — shift all tiles to the left
* **→ (Right)** — shift all tiles to the right


## 📜 Rules
1. **Moving tiles:** Each time you press an arrow key, all tiles on the board slide as far as they can in the chosen direction.
2. **Merging:** When two tiles with the same value collide while moving, they merge into a single tile with a value equal to their sum (2 + 2 = 4, 4 + 4 = 8, etc.).
3. **New elements:** After every successful move, a new tile with a value of `2` (or occasionally `4`) appears in an empty space.
4. **Game over:** The game ends in a loss when there are no empty spaces left on the board and no possible moves to merge tiles. Your goal is to score as many points as possible and reach the coveted **2048** tile! 🏆


## 💻 Getting Started (Run Locally)

Clone the project

```bash
  git clone https://github.com/diiyavol/landing_page-nothing.git
```

Go to the project directory

```bash
  cd landing_page-nothing
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start
```
